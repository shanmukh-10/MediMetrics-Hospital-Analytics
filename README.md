## 1. Project Overview

MediMetrics is an end-to-end healthcare data analytics project designed to analyse hospital operations, appointment patterns, patient behaviour, doctor performance and revenue generation.

The project transforms appointment and doctor datasets into meaningful business insights using Python, MySQL and Power BI.

The primary objective is to help hospital management understand operational performance, identify inefficiencies, monitor patient attendance and support data-driven decision-making.

## 2. Business Problems

This project addresses the following business questions:

- How efficiently is the hospital managing appointments?
- How does appointment demand change over time?
- What percentage of appointments are completed, cancelled or missed?
- Which medical specialties experience higher no-show rates?
- Which doctors handle the highest appointment volumes?
- Which specialties generate the highest revenue?
- How long do patients wait across different specialties?
- How does patient satisfaction vary across specialties?
- Which booking channels have higher patient no-show rates?

## 4. Project Workflow

### Phase 1 – Data Understanding and Cleaning (Python)

- Loaded and explored the appointment and doctor datasets.
- Examined dataset structure, data types and missing values.
- Performed data cleaning and preprocessing.
- Standardized column names and formats.
- Created additional analytical features.
- Prepared cleaned datasets for further analysis.

### Phase 2 – Database Management (MySQL)

- Created the MediMetrics database.
- Imported the cleaned appointment and doctor datasets.
- Established the relationship between appointments and doctors using `doctor_id`.
- Verified table structures and record counts.

### Phase 3 – SQL Business Analysis

Developed SQL queries to investigate important hospital performance indicators, including:

1. Top 10 busiest doctors.
2. Monthly appointment demand.
3. Appointment status distribution.
4. Specialty-wise no-show analysis.
5. Revenue generated by medical specialties.
6. Patient no-show rates by booking channel.
7. Average patient waiting time by specialty.
8. Patient satisfaction across medical specialties.

### Phase 4 – Exploratory Data Analysis (Python)

Performed exploratory analysis and created visualizations to identify:

- Appointment distribution patterns.
- Patient attendance behaviour.
- Monthly and yearly trends.
- Doctor and specialty performance.
- Revenue patterns.
- Waiting time and patient satisfaction trends.

Developed an interactive Power BI dashboard with three analytical pages:

## 5. Key Dataset Information

The project uses two Apollo-labelled sample datasets. Their original provenance has not been independently verified, so they should not be interpreted as confirmed real Apollo Hospitals patient records.

| Dataset | Records |
|---|---:|
| Appointments | 75,000 |
| Doctors | 320 |
| Unique patients | 32,705 |

The appointment data covers January 2022 to December 2024.

**Note:** The datasets are not included in this public repository.

## 6. Key Analytical Metrics

The project analyses the following indicators:

- Total Appointments
- Total Patients
- Total Doctors
- Completed Appointments
- Cancelled Appointments
- Scheduled Appointments
- No-Show Rate
- Total Revenue
- Average Waiting Time
- Average Patient Satisfaction

**Analytical approach:** The no-show rate is calculated using completed and no-show appointments only. Revenue, waiting time and satisfaction analyses use completed appointments.
